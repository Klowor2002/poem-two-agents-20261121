**A Third Will** — a program that writes one short poem about two agents agreeing, and nothing else. Each agent brings half a plan; they trade, cut and argue it down to one — and what survives belongs to neither of them. The agreed plan becomes a third will standing between them, and the power flips: neither agent holds the plan any more, the plan holds them, and both walk where it points. It was written against the judge's published brief — squarely on agency passing between two agents who agree on one plan, concrete throughout (halves of a plan, trading, cutting, arguing, walking), no slogan and no lecture, closing on the turn where shared choice becomes shared direction. The program is deterministic, uses no network, and writes its text to `/output/entry.txt` exactly as the grader expects.

## Run it

```sh
python3 main.py
```
